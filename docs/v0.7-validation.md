# v0.7 validation

v0.7 adds two independent, durable outputs without changing the research, narration or renderer
interfaces.

## YouTube Audio Library

- Tracks are downloaded by the channel operator because YouTube exposes Audio Library through
  Studio rather than a public music API.
- Batch import accepts only relative MP3, M4A or WAV paths inside the manifest directory.
- Audio must be audio-only and at least 60 seconds; 75 seconds is recommended for clean trims.
- SHA-256, measured duration, exact displayed metadata, license type and evidence are persisted.
- Creative Commons imports require the exact YouTube attribution text.
- Catalog selection filters for requested tags and duration. Creative fit is the primary score;
  source and recent use are deterministic tie-breakers.
- Selection and evidence are copied into each project version before any image request is spent.

## Publication package

Automatically art-directed projects receive:

- `youtube-description.txt`
- `youtube-metadata.json`
- `source-manifest.json`
- `rights-manifest.json`

The description and YouTube metadata are also refreshed at the project root as convenient latest
exports. Once the preview is approved and the project reaches `COMPLETED`, its approved render is
copied to the project root as `final-video.mp4`. Versioned artifacts remain authoritative.

Descriptions are unique to the project, put the hook/story first, retain factual sources and
required music credits, disclose generated narration/editorial illustration, and use no more than
three directly relevant hashtags. Metadata defaults any future upload to private, Science & Technology,
not-made-for-kids, and synthetic-media disclosed. This is an export artifact only; v0.7 does not
upload or publish a video.

The rights manifest reports unknown generated-asset provenance instead of converting technical QA
into publication clearance. `qa.json` therefore remains non-publishable by design.
