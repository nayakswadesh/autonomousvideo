# Autonomous Studio v1.0 — Final Scope

Status: implemented and under live OAuth validation

v1.0 closes the gap between a cleared local publication package and a safely reviewable YouTube
draft. It contains exactly these production-delivery changes:

1. Full Telegram productions are created at 1080×1920. The editorial compositor retains its
   stable layout coordinate system while source artwork and final frames render at full size.
2. Approving a full-video script immediately acknowledges the decision in Telegram before the
   worker continues with visuals, music, mixing, and rendering.
3. A local installed-app OAuth flow confirms that the signed-in YouTube channel matches an
   operator-supplied public handle. It requests only video-upload and read-only YouTube scopes and
   stores credentials only in the ignored `secrets/` folder.
4. `/uploadyoutubeshorts <project-id>` and `upload-youtube-short <project-id>` upload only a
   completed, publication-cleared package as private, not made for kids, with subscriber
   notifications disabled and the selected thumbnail applied.
5. Upload attempts and outcomes are durable and idempotent. Source hashes are verified; confirmed
   videos are not uploaded twice; thumbnail-only failures do not replay video data; ambiguous
   outcomes require manual inspection in YouTube Studio.

The first live upload is intentionally a private test. Public publishing, scheduling, YouTube
processing/analytics polling, automatic comment handling, and automatic learning from channel
performance are not part of v1.0.

Reliability amendment: directing uses durable background Responses with prompt-bound validated
narrative checkpoints. Response IDs and polling status survive worker restarts; retries resume the
same server-side response and skip completed narration. Shot-plan requests use low reasoning and
low response verbosity because they transform a locked story rather than create a new one.
