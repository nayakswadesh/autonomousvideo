# Autonomous Studio v0.6 scope

v0.6 turns the existing editorial renderer into a narration-led visual system. It preserves the
local-first, resumable v0.5 workflow and changes how new live projects are directed, illustrated,
rendered and packaged.

## Visual contract

- Every narrated shot declares why it is an image, metric overlay, timeline, chart, map, or an
  intentional text-only exception.
- Maps are used only by geographic `map` shots. A `big_metric` never receives a generic world-map
  fallback.
- Quantitative comparisons and charts display a category, formatted value and unit for every
  plotted item. Existing projects recover these labels from their referenced numeric claims;
  newly directed projects must author them explicitly. Maps name their marked location, timelines
  state both when and what happened, and metric/rank scenes keep the unit visible.
- Generated art is full bleed. The renderer overlays one primary headline, an optional
  non-repetitive annotation and timed captions.
- Shot numbers, repeated series chrome, source labels, review-copy labels and provenance labels do
  not occupy the story canvas.
- Citations remain attached to claims and artifacts. Music credit, source URLs and disclosure text
  are exported in `publication-description.txt` for the publishing workflow.

## Ending contract

New full productions use a semantic loop. The final narration is a complete sentence that closes
the story on first viewing and naturally leads back to the exact opening hook on replay. The final
shot is narrated, returns to the opening title and shares its source illustration. Source cards,
silent credits and fades to black are not valid final scenes.

## Image and thumbnail archive

Every rendered version creates `images/vNNN/` inside the project directory. It contains:

- one composed still for every shot;
- every clean source illustration used by those shots; and
- `manifest.json`, which identifies the opening frame as the initial thumbnail recommendation.

All entries are persisted as versioned `thumbnail_candidate` artifacts. Their provenance and
usage restrictions remain in project metadata even though that technical copy is not burned into
the pixels.

## Acceptance checks

- A non-geographic metric cannot invoke the map renderer.
- Generated live stories cannot contain a `source_card`.
- A semantic-loop full story must finish on a narrated outro, preserve a complete bridge sentence,
  return to the hook and use the same opening/closing image.
- Image-backed visual strategies must resolve to generated assets; intentional text-only narration
  is limited and requires a rationale.
- On-screen annotations cannot simply repeat the headline or narration.
- The publication description and complete image gallery must exist before preview approval.
- Existing v0.5 project records remain loadable and renderable.
