# v0.4 validation — 2026-09-14

## Scope and implementation

Automatic asset planning, bounded OpenAI Images generation, and deterministic licensed local
music selection now run after measured narration and before mixing/rendering. No earthquake
branch exists in the provider or orchestration code. Offline fixtures exercise earthquake
and solar-system briefs with the same engine. New live topics use this path by default;
manual manifests and the original no-key mock workflow remain available.

The operator recovery command revalidates a cached response without resetting attempt counters,
making a paid call or changing creative version. It rejects stale versions, paths outside the
project cache, accepted plans and already-dispatched images. Failed planner attempts now persist
their validation reasons and available provider traces.

Two bugs were corrected during acceptance:

- Numeric validation inspected ASCII-escaped JSON, misreading `≈243,000` and `1–3`. It now
  compares complete displayed numbers (not JSON escape digits, shot IDs or timing metadata).
- A ranking headline box was two pixels too short for two lines at the minimum readable font
  size. Its height now accommodates both lines without changing text or overlapping the metric.

The OpenAI Docs and image-generation skills informed the API contract checks, image prompt
constraints, no-archival-evidence disclosure and visual inspection. Images were produced by the
studio's reusable OpenAI Images API adapter, as authorized for unattended operation, rather than
the chat image tool. API reference: https://developers.openai.com/api/reference/resources/images/methods/generate

## Boundaries

This is a 15-second documentary excerpt, not the future 45–60-second release. The underlying
earthquake ranking remains provisional, scoped to reported deaths since 1900, with disputed
and unverified claims visibly documented. It is not an all-history or magnitude ranking.
Artwork and speech still require rights/creative review; `publishable=false` is retained.
Music selection is from a curated local catalog, not autonomous web licensing.
No publishing, extra image allowance, API model upgrade or agent-issued approval was performed.
Telegram is a local background worker: the computer must remain awake and connected; it is
not yet a startup service. Checkpointed delivery is at-least-once, not an exactly-once guarantee
across a crash immediately after sending.
